## 5. Pipeline Setup Now Supports Pixi, Conda & Spack 🧪

You can now run `rnaseq_full` pipelines with **Pixi**, **Conda**, or **Spack**, including in **GitHub Codespaces**, **macOS**, and all major **Linux distros**.

With `pixi install && pixi run rnaseq`, setup takes **under 2 minutes**, and Pixi is now **preinstalled** in Codespaces for easy access, all thanks to **Vaibhav**!

<hr className="my-12 border-gray-300" />

**David & Isolde** shipped some updates to our analytics funnel!

## 7. Rust-Based Tracer Installer: Merged & Live!

Big milestone on two fronts for the new **Rust-based Tracer installer,** shout out to **David**!

✅ **Live on Sandbox Onboarding**: The installer is also fully deployed on the sandbox onboarding page, featuring environment detection, root/dependency validation, binary handling, and analytics events (`INSTALL_SCRIPT_STARTED` / `COMPLETED`).

✅ **Merged into `main`**: The new Rust binary installer is now part of the codebase. This brings more reliable installs, easier debugging, and fewer setup issues. Minor validation is ongoing (e.g. `sudo` on macOS), with `chmod` improvements coming soon.

Together, these updates mark a major leap in how Tracer is installed. Smoother for users, better for the team.
